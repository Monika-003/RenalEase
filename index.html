About RenalEase

RenalEase is a final-year engineering project focused on developing a compact, battery-powered dialysis monitoring prototype.

The project explores sensor-based monitoring, micro-pump mechanisms, alerts and the possibility of remote observation through IoT technology.

Project Highlights

  • Arduino-based monitoring concept
  • Temperature and pressure sensor integration
  • Heart-rate monitoring concept
  • Battery-powered prototype
  • Remote monitoring as a planned extension
Important: RenalEase is an engineering prototype, not a clinically validated or approved dialysis machine. This website is a demonstration interface and must not be used for medical decisions.
